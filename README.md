# 🌌 Universal-Cloud-Grabber

### 🚀 How to use
1. Go to **Actions** -> **Universal-Cloud-Grabber**.
2. Click **Run workflow**.
3. Paste a **Direct Link** OR a **GitHub Repo** (e.g., `user/repo`) and run.
4. Refresh this page in 1 minute.
