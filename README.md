# 🌌 Universal-Cloud-Grabber

### 🚀 How to use
1. Go to the **Actions** tab at the top.
2. Select **Universal-Cloud-Grabber** on the left sidebar.
3. Click the **Run workflow** button (right side).
4. Paste your link (Direct Download or GitHub `user/repo`) and click **Run workflow**.
   - *Tip: Type `CLEAR` in the box to wipe all files and logs.*
5. Refresh this page in about 1 minute to see your links.

### 🛠️ Technical Details
- **Max File Size:** Unlimited (Files over 95MB are automatically split).
- **GitHub Links:** Downloads all assets from the latest release.
- **Link Type:** Uses `raw.githubusercontent.com` for better access in filtered regions.
- **Privacy:** Each new download replaces the previous one.

*Built with ❤️ using GitHub Actions*# 🌌 Universal-Cloud-Grabber

### 🚀 How to use
1. Go to **Actions** -> **Universal-Cloud-Grabber**.
2. Click **Run workflow**.
3. Paste a **Direct Link** OR a **GitHub Repo** (e.g., `user/repo`) and run.
4. Refresh this page in 1 minute.
