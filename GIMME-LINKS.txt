# 🌌 Universal-Cloud-Grabber

### 🚀 How to use
1. Go to the **Actions** tab at the top.
2. Select **Universal-Cloud-Grabber** on the left sidebar.
3. Click the **Run workflow** button (right side).
4. Paste your link (Direct Download or GitHub `user/repo`) and click **Run workflow**.
   - *Tip: Type `CLEAR` in the box to wipe all files and logs.*
5. Refresh this page in about 1 minute to see your links.

### 🛠️ Technical Details
- **Max File Size:** 1-2 GB (Files over 95MB are automatically split).
- **GitHub Links:** Downloads all assets from the latest release.
- **Privacy:** Every new download replaces the previous one.
- **Log:** The last link used is stored in `GIMME-LINKS.txt`.

*Built with ❤️ using GitHub Actions*
