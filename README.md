# 🌌 Universal-Cloud-Grabber

### 🚀 How to use
1. Go to the **Actions** tab.
2. Select **Universal-Cloud-Grabber**.
3. Click **Run workflow**.
4. Paste your link (e.g., `KaringX/karing` or `https://github.com/KaringX/karing/`) and hit **Run workflow**.
5. Wait 1 minute and refresh this page.
